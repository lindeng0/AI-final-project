# Method Summary

## 1. Traditional keyword-based digital index

The traditional index is built from cleaned SEC 10-K/10-Q filing text. The pipeline detects digital-transformation-related keyword hits and groups them into conceptual categories such as:

- Deployment / digital channels: e.g., online banking, mobile banking, digital banking, internet banking, remote deposit capture.
- Capability / technology capability: e.g., data analytics, automation, cloud, API, platform, artificial intelligence, machine learning.
- Risk / technology risk disclosure: e.g., cybersecurity, information security, data breach, technology risk.

The final firm-year index is a relative 0-100 traditional keyword-based disclosure intensity measure. Because it is scaled/rank-like, its mean and median are mechanically close to 50 in the full sample.

Main scripts:

```text
src/04_traditional_index/extract_keyword_level_hits.py
src/04_traditional_index/build_revised_traditional_scores.py
src/04_traditional_index/build_final_traditional_firm_year_index.py
src/04_traditional_index/clean_final_traditional_firm_year_index.py
```

Main variable:

```text
Traditional_index_0_100
```

## 2. AI full-document semantic index

The AI index is generated by a Poe-hosted ChatGPT model. The model reads the full HTML-parsed visible text of each filing and returns JSON scores on four 1-5 dimensions:

1. Investment Type
2. Strategic Importance
3. Implementation Stage
4. Time Horizon

The four scores are averaged and transformed to a 0-100 index:

```text
AI_index_0_100 = (average_score - 1) / 4 * 100
```

Firm-year aggregation follows an annual-first rule: if a successfully scored 10-K is available, use the 10-K; otherwise use available 10-Q filings as fallback.

Main scripts:

```text

src/05_ai_semantic_scoring/score_filings_with_poe_fulltext.py
src/05_ai_semantic_scoring/aggregate_ai_fulltext_scores_to_firm_year.py
```

Main variable:

```text
AI_full_document_index_0_100_v3
```

## 3. Final panel

The final panel merges:

- Traditional digital disclosure index
- AI full-document semantic index
- ROA
- Annual stock return
- Log assets
- Log market capitalization
- 2020-2022 COVID exposure

Main scripts:

```text

src/06_final_panel/build_final_2018_2024_panel.py
src/06_final_panel/build_stock_return_from_compustat.py
src/06_final_panel/merge_stock_return_into_final_panel.py
```
