# AI-Based Digital Transformation Disclosure in U.S. Banks

## Project overview

This repository contains the cleaned code pipeline for a final project that measures and evaluates **digital transformation disclosure in U.S. banks** using SEC filings. The project builds two complementary digital-transformation measures:

1. **Traditional keyword-based digital disclosure index**  
   A dictionary/keyword-based 0-100 relative index constructed from digital-transformation-related keyword hits in SEC 10-K/10-Q filings.

2. **AI full-document semantic digital transformation index**  
   A Poe/ChatGPT-based semantic score generated by asking an AI model to read the full HTML-parsed visible text of each SEC filing and rate the strategic substance of digital transformation disclosure.

The final analysis panel covers **2018-2024** at the **bank firm-year** level. It combines digital disclosure indices, accounting performance, approximated annual stock returns, size controls, market capitalization, and COVID exposure variables.

The central question is:

> Do AI-based semantic measures of digital transformation disclosure capture information beyond traditional keyword-based disclosure intensity, and are these measures associated with bank performance, especially during the COVID period?

## Data pipeline logic

The project follows seven broad stages:

```text
1. Build bank/COVID/performance source panels
2. Download and clean SEC 10-K/10-Q filings
3. Construct traditional keyword-based digital index
4. Construct AI full-document semantic index
5. Merge traditional + AI indices
6. Add accounting performance, stock return, controls, and COVID exposure
7. Run descriptive analysis and regressions
```

A simplified workflow is:

```text
Raw SEC filings
  -> HTML-visible clean text
  -> keyword extraction -> traditional index
  -> Poe/ChatGPT full-document reading -> AI semantic index
  -> firm-year aggregation
  -> merge with ROA, stock return, controls, COVID exposure
  -> final regression analysis
```

## Traditional keyword-based index

### Concept

The traditional index is designed to approximate **digital disclosure intensity** using a manually curated digital-transformation keyword dictionary. It captures whether a filing contains many terms associated with digital banking, digital services, automation, analytics, cybersecurity, technology infrastructure, and related transformation themes.

It is best interpreted as:

> A relative keyword-based measure of digital-related disclosure intensity.

It is **not** a direct measure of the semantic quality, strategic depth, or implementation maturity of digital transformation.

### Traditional index construction logic

The core steps are:

```text
1. Start from cleaned SEC filing text.
2. Detect keyword hits using the digital-transformation dictionary.
3. Count hits by keyword and category.
4. Construct filing-level digital disclosure measures.
5. Aggregate filing-level scores to the firm-year level.
6. Scale the resulting firm-year score to a 0-100 relative index.
```

Important output variables include:

```text
Traditional_score
Traditional_index_0_100
Traditional_score_tfidf
Traditional_index_risk_adjusted_0_100
Digital_risk_disclosure_score
```

The main traditional measure used in regressions is:

```text
Traditional_index_0_100
```

### Interpretation note

`Traditional_index_0_100` is a relative/rank-like 0-100 index. Therefore, its mean and median are mechanically close to 50 in the final sample. This should not be interpreted as the average bank having a “digital transformation level of 50.” It is better interpreted as a relative disclosure-intensity ranking.

## AI full-document semantic index

### Concept

The AI index is designed to capture the **semantic substance** of digital transformation disclosure. Instead of only counting digital keywords, the model reads the full cleaned filing text and evaluates whether the disclosure reflects meaningful digital transformation.

It is best interpreted as:

> A full-document semantic assessment of whether a bank’s SEC filing contains strategically meaningful, implemented, and long-horizon digital transformation disclosure.

### Source text

The model does not read raw HTML directly. The pipeline first converts raw SEC filing HTML into visible plain text:

```text
raw HTML filing
  -> remove HTML tags, hidden XBRL metadata, scripts, styles, taxonomy artifacts
  -> HTML-parsed visible clean text
  -> Poe/ChatGPT full-document scoring
```

This design keeps the task close to “reading the filing” while reducing noise from HTML/XBRL artifacts.

### AI model

The AI scoring pipeline uses a Poe-hosted ChatGPT model through the Poe OpenAI-compatible API.

Typical model setting:

```text
POE_MODEL=GPT-4o-mini
```

The API key should be supplied through an environment variable and should never be committed to GitHub:

```text
POE_API_KEY=your_key_here
```

Use:

```text
docs/poe.env.template
```

as the template.

### AI scoring rubric

For each filing, the AI model scores four main dimensions from 1 to 5:

| Dimension | Interpretation |
|---|---|
| Investment Type | Whether the digital content reflects routine IT, process improvement, transformation, or strategic innovation. |
| Strategic Importance | Whether digital transformation is incidental or central to strategy, competitiveness, growth, and customer experience. |
| Implementation Stage | Whether digital initiatives are conceptual, planned, piloted, deployed, or operationalized across functions. |
| Time Horizon | Whether the disclosure reflects short-term operations or longer-term modernization/transformation. |

An auxiliary dimension is also scored:

| Auxiliary score | Interpretation |
|---|---|
| Digital Relevance | Whether the filing contains little, generic, moderate, clear, or highly substantive digital transformation content. |

The model also returns a confidence score and a short explanation.

### AI index formula

The four main 1-5 scores are averaged:

```text
AI_full_document_score = mean(
    InvestmentType,
    StrategicImportance,
    ImplementationStage,
    TimeHorizon
)
```

Then the score is converted to a 0-100 index:

```text
AI_full_document_index_0_100_v3 = (AI_full_document_score - 1) / 4 * 100
```

The main AI variable used in analysis is:

```text
AI_full_document_index_0_100_v3
```

### Firm-year aggregation

The AI scoring is initially performed at the filing level. It is then aggregated to the firm-year level using an annual-first rule:

```text
If a successfully scored 10-K exists for the firm-year:
    use the 10-K score.
Else:
    use available successfully scored 10-Q filings as fallback.
```

This gives priority to annual reports, while still preserving firm-years when a 10-K was unavailable or failed due to technical limits.

### Important AI missingness note

A small number of filings failed because the full text exceeded the model context limit. Missing AI scores are technical missingness and should not be treated as zero digital transformation.

## Evidence-snippet experiment

During development, the project also tested an evidence-snippet scoring approach:

```text
Python extracts digital-transformation evidence snippets
  -> Poe/ChatGPT scores only the snippets
```

The comparison between evidence-snippet scoring and full-document scoring showed that the two approaches produced similar average levels but diverged at the filing level. This suggests that AI semantic scoring is sensitive to input design.

For the final project, the main measure is the **full-document AI score**, because:

```text
1. It is easier to explain as “AI reads the filing.”
2. Poe quota was sufficient for full-document scoring.
3. It avoids making the main result depend only on retrieval-selected snippets.
4. It better matches the final-project objective rather than a publication-level measurement validation exercise.
```

The evidence-snippet experiment is useful as a discussion/robustness point.

## Performance and control variables

### Accounting performance

Main accounting outcome:

```text
ROA_annual_mean
```

This is the annual mean of quarterly ROA.

### Stock performance

Main stock outcome:

```text
StockReturn_annual_compound_w
```

It is constructed from Compustat quarterly price data (`prccq`):

```text
quarterly_return = prccq / lag(prccq) - 1
annual_return = product(1 + quarterly_return) - 1
```

The winsorized version is used in the main analysis.

Important limitation:

> This is a price-return approximation based on Compustat quarterly prices, not a CRSP dividend-adjusted total return.

## Main descriptive patterns

### 1. Traditional and AI indices capture different information

The traditional keyword index and AI full-document semantic index are positively but only weakly/moderately correlated. This suggests that:

```text
Traditional index = keyword disclosure intensity
AI index = semantic and strategic substance
```

This is central to the project’s measurement contribution.

### 2. Traditional index is relatively stable over time

Because the traditional index is scaled as a relative 0-100 measure, its distribution is close to rank-like. Its mean and median are mechanically close to 50.

This makes it useful for relative comparisons, but less useful for interpreting raw disclosure growth over time.

### 3. AI index shows more meaningful time variation

The AI index shows a stronger increase around 2020 and again after 2022. This suggests that the AI measure may capture changes in the strategic substance of digital transformation narratives that are not fully reflected in keyword intensity.

### 4. AI scores are discrete

The AI index is based on four 1-5 rubric scores, so the final 0-100 measure is naturally discrete. Values often appear at fixed intervals such as 0, 25, 37.5, 50, 56.25, 62.5, 68.75, and 75.

This is expected and not an error.

## Main empirical findings

### Finding 1: AI index predicts stock performance better than traditional index

In pooled year fixed-effect regressions with log assets as a control, the AI full-document semantic index is positively associated with annual stock return, while the traditional keyword index is not.

Interpretation:

> Investors appear to respond more to semantically substantive digital transformation disclosure than to simple digital keyword intensity.

This is the main empirical result.

### Finding 2: No robust relationship with ROA

Neither the traditional index nor the AI index shows a robust statistically significant relationship with annual ROA.

Interpretation:

> Digital transformation disclosure may be reflected more quickly in market expectations than in contemporaneous accounting profitability.

ROA is also affected by many banking-specific forces, including interest-rate conditions, loan loss provisions, asset quality, balance-sheet structure, and macroeconomic shocks.

### Finding 3: COVID exposure attenuates the AI-stock-return relationship

In the 2020-2022 COVID subsample, the AI index remains positively related to stock return, but the interaction between AI index and local COVID exposure is negative.

Interpretation:

> Digital transformation disclosure is generally rewarded by the market, but this benefit is weaker in areas with higher COVID exposure.

This suggests that strong local pandemic shocks may offset part of the market benefit associated with digital transformation disclosure.

### Finding 4: Firm fixed effects weaken the AI-stock-return result

When firm fixed effects are added, the AI-stock-return association becomes weaker and less significant.

Interpretation:

> The AI signal is driven more by cross-sectional differences across banks than by within-bank year-to-year changes.

This is reasonable because digital transformation capability and disclosure style may be relatively stable firm-level strategic characteristics.

## Regression design

The clean main regressions are in:

```text
src/07_analysis/run_final_regressions.py
```

Main outcomes:

```text
ROA_annual_mean
StockReturn_annual_compound_w
```

Main regressors:

```text
Traditional_index_0_100
AI_full_document_index_0_100_v3
```

Main control:

```text
LogAssets_annual_mean
```

Baseline model family:

```text
Outcome_it = beta_1 Traditional_it + Controls_it + YearFE_t + error_it
Outcome_it = beta_1 AI_it + Controls_it + YearFE_t + error_it
Outcome_it = beta_1 Traditional_it + beta_2 AI_it + Controls_it + YearFE_t + error_it
```

COVID interaction models are restricted to the 2020-2022 COVID exposure subsample:

```text
Outcome_it = beta_1 AI_it + beta_2 COVIDExposure_it
             + beta_3 AI_it * COVIDExposure_it
             + Traditional_it + Controls_it + YearFE_t + error_it
```

Firm fixed-effect versions are used as robustness checks.

## Important notes and limitations

1. **Raw and large intermediate data are excluded from GitHub.**  
   Raw SEC filings, raw FDIC SOD files, large keyword-window files, and external COVID raw files are too large for a clean GitHub repository.

2. **Never commit Poe API keys.**  
   Use environment variables and `docs/poe.env.template`.

3. **AI missing values should not be filled with zero.**  
   Most AI missingness reflects technical context-length failures, not absence of digital transformation.

4. **COVID variables are intentionally missing outside 2020-2022.**  
   This is by design, not a merge error.

5. **Stock return is an approximation.**  
   It is constructed from Compustat quarterly `prccq` and does not include dividends or CRSP total-return adjustments.

6. **Traditional index is rank-like.**  
   Its mean and median are close to 50 by construction, so it should be interpreted as a relative disclosure-intensity measure.

7. **AI index is rubric-based and discrete.**  
   Its discrete distribution reflects the 1-5 scoring rubric.

8. **Firm fixed-effect results are weaker.**  
   The main AI-stock-return relationship is primarily cross-sectional.

## Suggested final-project interpretation

A concise interpretation of the project is:

> Traditional keyword measures and AI semantic measures capture different aspects of digital transformation disclosure. The traditional index measures how intensively banks use digital-related language, while the AI full-document index evaluates whether the filing describes substantive and strategically meaningful digital transformation. The AI semantic score is more strongly associated with stock-market performance than the traditional keyword index, suggesting that investors respond to the strategic substance of digital transformation disclosure rather than keyword intensity alone. However, this market benefit is weaker in areas with higher COVID exposure, and the results are less robust with firm fixed effects.

## Recommended citation / acknowledgement language

This project uses SEC 10-K/10-Q filings, Compustat-style quarterly financial variables, FDIC Summary of Deposits-style bank data, COVID exposure measures, and Poe-hosted ChatGPT semantic scoring. The AI score is a research-constructed measure and should be interpreted as a model-assisted textual disclosure measure rather than an independently verified measure of actual internal digital transformation.
